# Flowchart-Projects-.fpp-
This repository contains a collection of flowchart files demonstrating various basic programming logic and algorithmic solutions. 

## Flowchart Overview

* **Number Comparison**: Compares two input numbers to determine whether they are equal or which one is greater[cite: 1].
* **Password Verification**: A basic authentication flowchart that prompts the user for a password (`2012`) and grants access upon success[cite: 2].
* **Addition Calculator**: Takes two numbers as input, performs an addition operation, and outputs the calculated result[cite: 3].
* **Driver's License Eligibility**: Calculates the user's age by subtracting their birth date from the current date and checks if they are 18 or older to see if they are eligible for a driver's license[cite: 4].
* **Personalized Greeting**: Asks for the user's name and displays a customized greeting message[cite: 5].
* **Perimeter Calculator**: Takes two side lengths as inputs, checks if they are equal to determine if the shape is a square or rectangle, and calculates the perimeter[cite: 6].
* **Number Sign Checker**: Evaluates an input number to check if it is zero, positive, or negative[cite: 7].
